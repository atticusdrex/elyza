elyza.core.evaluator module#

The evaluator class: a way to evaluate external computer models and store data.

Defines Evaluator, which wraps an arbitrary evaluation function together with its Input specification, output dimension, and (optionally) a calibrated per-evaluation cost – the unit that elyza.multifidelity estimators operate on.

class elyza.core.evaluator.Evaluator(*, name: int | str, inputs: list[Input], output_dim: int = 1, evaluation_func: Callable | None = None, cost: float | None = None, jit_compile: bool = False)[source]#

Bases: BaseModel
