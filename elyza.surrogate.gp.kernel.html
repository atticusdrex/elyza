elyza.surrogate.gp.kernel module#

Covariance kernels used by GaussianProcess.

Every kernel exposes an eval(x1, x2, params) method and a p_dim computed field giving the number of raw parameters it expects; params are always passed through softplus() inside eval so that unconstrained (e.g. optimizer-facing) parameters map to strictly positive amplitude/bandwidth values.

Each kernel also provides init_params(input_var, output_var), which the GP models call to get a data-driven starting point for the raw parameters.

init_params(input_var, output_var)[source]#

Data-driven initial raw parameters for a [amplitude, bandwidth(s)] layout.

The amplitude is set to the output variance and the bandwidth(s) to 2 * Var(x), since E[(x_i - x_j)^2] = 2*Var(x) for iid x_i, x_j (matching the exp(-d^2/bandwidth) form). Kernels whose parameters have a different layout or meaning override this.

Parameters:

  • input_var – Per-dimension variance of the (scaled) training inputs, shape (input_dim,).

  • output_var – Scalar variance of the training outputs.

Returns:

Raw (unconstrained) parameter array of length p_dim.

class elyza.surrogate.gp.kernel.Linear(*, input_dim: int, epsilon: float = 1e-12, dtype: _ScalarMeta = <class 'jax.numpy.float64'>)[source]#

Bases: BaseKernel

ARD linear (dot-product) kernel: b + sum_i w_i * x1_i * x2_i.

Non-stationary; a GP with this kernel is Bayesian linear regression with per-dimension weight variances w_i and bias variance b. The kernel matrix has rank at most input_dim + 1, so it relies on the GP’s noise variance for a stable Cholesky factorization. Note that the name is shared with Linear; import it via the module (kernel.Linear) or alias it if both are needed.

Sample paths are continuous but not differentiable. Unlike Laplace this uses the 2-norm, so it is rotation-invariant up to the per-dimension bandwidths.

class elyza.surrogate.gp.kernel.Periodic(*, input_dim: int, epsilon: float = 1e-12, dtype: _ScalarMeta = <class 'jax.numpy.float64'>)[source]#

Bases: BaseKernel

ARD periodic (exp-sine-squared) kernel.

k(x1, x2) = a * exp(-sum_i sin^2(pi * (x1_i - x2_i) / period_i) / bandwidth_i)

Each input dimension has its own period and bandwidth. Note that the marginal likelihood is typically multimodal in the periods, so the fit can be sensitive to their initial values.

Isotropic (single-bandwidth) radial basis function kernel.

eval(x1, x2, params)[source]#

Evaluate the RBF kernel between two points.

To obtain the exact amplitude and lengthscale for the kernel l * exp(-||x - x'||^2 / (2*sigma^2)), convert params via:

l = softplus(params[0])
sigma = sqrt(0.5 * softplus(params[1]))

class elyza.surrogate.gp.kernel.RationalQuadratic(*, input_dim: int, epsilon: float = 1e-12, dtype: _ScalarMeta = <class 'jax.numpy.float64'>)[source]#

Bases: BaseKernel

ARD rational quadratic kernel: a * (1 + r^2 / alpha)^(-alpha).

Here r^2 = sum_i (x1_i - x2_i)^2 / bandwidth_i. It is a scale mixture of RBF kernels with different lengthscales, and recovers ARD (a * exp(-r^2)) as alpha -> inf.
