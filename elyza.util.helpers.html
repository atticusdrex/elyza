elyza.util.helpers module#

Standalone numerical helper functions used throughout elyza.

Includes covariance/correlation utilities, a robust least-squares wrapper, shape-normalization helpers, a Gaussian KL-divergence, greedy inducing-point selection, elementwise activation functions and their inverses, and a vectorized kernel-matrix evaluator.

elyza.util.helpers.cholesky_KL_div(mu_q, L_q, mu_p, L_p)[source]#

KL divergence KL(q || p) for Gaussians parameterized by Cholesky factors.

Parameters:

  • mu_q – Mean vector of q, shape (k,).

  • L_q – Lower-triangular Cholesky factor of q’s covariance, shape (k, k).

  • mu_p – Mean vector of p, shape (k,).

  • L_p – Lower-triangular Cholesky factor of p’s covariance, shape (k, k).

Returns:

Scalar KL divergence KL(q || p).

Return type:

jax.Array

elyza.util.helpers.ensure_2d(X)[source]#

Reshape an array to be at least 2-dimensional.

Scalars become shape (1, 1) and 1-d arrays become column vectors of shape (-1, 1); arrays that are already 2-d (or higher) pass through unchanged.

Parameters:

X – Input array of any rank.

Returns:

X with rank at least 2.

Return type:

jax.Array

elyza.util.helpers.greedy_k_center(key, X: Array, k: int)[source]#

Greedy k-centers selection of inducing inputs.

Starting from a random point, repeatedly selects the point farthest (in Euclidean distance) from the already-selected set, giving a set of k points that spreads coverage over X.

Parameters:

  • X – Candidate points, shape (n_points, n_features).

  • k – Number of centers to select.

  • seed – Seed for the initial random point.

Returns:

(selected_points, selected_indices) where selected_points has shape (k, n_features) and selected_indices is the list of row indices into X.

Return type:

tuple

elyza.util.helpers.kernel_mat(X1, X2, kernel, kernel_params)[source]#

Compute the full kernel matrix between two point sets.

Parameters:

  • X1 – First set of points, shape (n1, input_dim).

  • X2 – Second set of points, shape (n2, input_dim).

  • kernel – A kernel object exposing eval(x, y, kernel_params) for a single pair of points.

  • kernel_params – Parameter array passed through to kernel.eval.

Returns:

Kernel matrix of shape (n1, n2) where entry (i, j) is kernel.eval(X1[i], X2[j], kernel_params).

Return type:

jax.Array

elyza.util.helpers.ls(A, B, rcond=None)[source]#

Solve the linear least-squares problem min ||A @ X - B||.

Thin wrapper around jax.numpy.linalg.lstsq() that returns only the solution array (not residuals, rank, or singular values).

Parameters:

  • A – Coefficient matrix of shape (m, n).

  • B – Right-hand side of shape (m, k) or (m,).

  • rcond – Relative condition number used to truncate small singular values; forwarded to jnp.linalg.lstsq.

Returns:

Least-squares solution X of shape (n, k) or (n,).

Return type:

jax.Array
